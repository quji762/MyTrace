# Pulse.Win 0.9.0

Windows release bar for the Mac app's quota rail and token-spend history.

Included: nineteen providers with display names, enablement that defaults on only when a local credential path exists or a secret is stored, Windows-local credential fallbacks (editor database, auth files, key files, plan database, arkcli when it can be invoked), Claude/Codex route pinning, paste-only browser cookies, opt-in token spend with separate Kilo and Pi-family sources, a durable last-good cache, and stable `windows-v*` update selection.

Not in this bar: browser-cookie decryption, Claude Desktop sessions, macOS-only integrations, hourly spend charts, and a signed public store submission.
